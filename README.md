# FleetPro

Enterprise Fleet Management System

## Overview

FleetPro is a desktop fleet management solution designed to manage:

- Vehicles
- Drivers
- Maintenance
- Inventory
- Fuel
- Expenses
- Reports

## Technology Stack

- C#
- .NET 10
- WPF
- MVVM
- Entity Framework Core
- SQL Server

## Architecture

Clean Architecture:

FleetPro.WPF
FleetPro.Application
FleetPro.Domain
FleetPro.Infrastructure

## Features

### Authentication
- User login
- Role management
- Permission control
